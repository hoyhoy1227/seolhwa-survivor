# 설화: 밤의 사냥꾼

위기에 빠진 여섯 한국 설화를 구하기 위해 수호자들이 싸우는 2D 픽셀 아트 생존 액션 캠페인입니다. 브라우저에서 설치 없이 바로 플레이할 수 있습니다.

## 바로 플레이

**[설화: 밤의 사냥꾼 실행하기](https://hoyhoy1227.github.io/seolhwa-survivor/)**

다운로드나 GitHub 로그인 없이 최신 Chrome, Edge, Safari 등 웹브라우저에서 실행할 수 있습니다. 위 공개 주소를 전달하면 누구나 같은 게임을 바로 플레이할 수 있습니다.

## 전체 소스 코드와 커밋 기록

- 저장소: **[hoyhoy1227/seolhwa-survivor](https://github.com/hoyhoy1227/seolhwa-survivor)**
- 게임 실행 코드, UI, 캐릭터·몬스터·배경 스프라이트, 배포 워크플로를 이 저장소에 함께 포함합니다.
- 기능 수정은 기존 기록을 덮어쓰지 않고 새로운 Git 커밋으로 추가합니다.

## 주요 특징

- 도깨비, 구미호, 해치, 산신, 처용, 바리데기 중 캐릭터를 선택하고, 6장 최초 클리어 후 세종대왕을 영구 해금
- 캐릭터 선택 후 여섯 설화가 위기에 빠진 배경과 여정의 목표를 소개하는 스토리 인트로
- 도깨비 장터, 여우고개, 해치의 금문, 산군 봉우리, 처용의 달궁, 바리의 저승꽃길로 이어지는 6장 캠페인
- 포탈 이동 후 새 설화의 지형 장치·전투 특징·밤의 보스를 읽고 직접 전투를 재개하는 맵 안내 화면
- 낮에서 밤으로 갈수록 출현 수와 빈도가 크게 증가하고, 2번째 설화부터 모든 적의 체력·공격력·출현량과 보스 체력이 크게 상승하는 동적 난이도
- 보스 등장 후 10초까지만 추가 몬스터가 생성되며 이후에는 남은 몬스터와 보스만 처치하는 마무리 전투
- 철퇴 지진파, 추적 여우불, 수호 파동, 관통 화살, 처용 연무, 연쇄 영혼꽃, 세종대왕의 한글 글자 비격 등 캐릭터별 고유 공격
- 회전 부적, 연꽃 진, 연쇄 낙뢰, 봉황의 불깃, 반사경 등 공격 방식을 바꾸는 성장·보물 아이템
- 운영체제의 이모지 글꼴에 의존하지 않는 내장 SVG 아이템 아이콘
- 몬스터 접촉 피해, 예고 범위, 준비·돌진·베기 단계가 보이는 공격 모션
- 카메라가 캐릭터를 따라가는 2400×1800 크기의 탐험형 전장
- 근거리 요괴 중심의 적 구성과 느린 원거리 무당형 적
- 이전보다 크게 높아진 체력과 2단계 폭주 패턴을 지닌 도깨비 대왕, 천년 구미호, 불가살이, 산군, 역신, 염라대왕 전투
- 보스 처치 시 남은 몬스터가 파란 경험치로 변하고, 맵의 모든 경험치가 캐릭터에게 날아와 도착할 때마다 수치에 반영
- 최종 보스 전 두 차례 등장하는 대형 중간 수호자와, 중간·최종 보스를 처치했을 때만 생성되는 중복 방지 보물
- 0.1초 이내 연속 보물 생성 시 기존 상자와 충분히 떨어진 후보 위치를 찾는 겹침 방지 배치
- 경험치는 기본적으로 캐릭터가 획득 반경 안으로 접근해야 끌려오며 `정기 복주머니`로 반경 확장 가능
- 보스 처치 직후 포탈 위 안내문과 화살표가 표시되며, 직접 포탈에 들어가야 다음 설화로 이동
- 경험치 바에 현재 경험치와 다음 레벨 필요량이 표시되며 레벨이 높아질수록 요구 경험치가 가속 증가
- 포목 좌판·여우 달문·금문 성벽·겹봉우리·달궁 기와·삼도천 등 설화별로 세밀하게 구성된 전장
- 전용 픽셀아트 스프라이트가 적용된 화로·안개석·금문 수호진·산바람 돌탑·처용 정화 북·저승 영혼샘
- 맵 장치는 평소에는 스프라이트만 표시되며 오라·문양·범위 효과는 실제 발동 시간에만 노출
- 환영·쇳조각·산바람·역병·저승 균열 경고 문양과 설화별 환경 입자 효과
- 전용 마법진, 다중 타격 섬광, 화살·칼날·영혼꽃 궤적과 지면 균열 등 강화된 공격 표현
- 밤에는 캐릭터가 든 호롱불 주변만 보이는 시야 시스템
- 캐릭터 걷기 동작, 보물상자 바운스와 개봉 광원 효과
- 절차적으로 생성되는 배경음악과 전투 효과음
- 시작, 캐릭터 선택, 일시정지, 재시작, 게임 오버 메뉴
- 데스크톱과 모바일 화면에 대응하는 반응형 UI

## 조작법

- 이동: 방향키 또는 `WASD`
- 마우스/터치: 화면을 누른 방향으로 이동
- 공격: 가장 가까운 적을 향해 자동 공격
- 일시정지: 화면 오른쪽 아래 버튼 또는 `Esc`

## 로컬 실행

저장소 루트에서 정적 웹 서버를 실행합니다.

```powershell
python -m http.server 8000
```

그다음 <http://localhost:8000>을 엽니다. 브라우저 보안 정책 때문에 `index.html` 파일을 직접 여는 것보다 로컬 서버 사용을 권장합니다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 [GitHub Actions 배포 워크플로](./.github/workflows/deploy-pages.yml)가 GitHub Pages에 자동으로 배포합니다.
